<h1 align="center">机械动力: 铜染光阴</h1>

一个机械动力附属模组，为含有铜材质的物品与方块添加了氧化变种及其氧化机制。

**其他语言版本:**
[English](../../README.md) | [简体中文](README.zh-CN.md)

**有什么新内容？请看** [更新日志](../../CHANGELOG.md)

## 特性

### 新增方块

为机械动力中**所有**含有铜材质的方块，添加了锈蚀的/斑驳的/氧化的/涂蜡的……共计 **7** 种氧化变种。

同时，原版的氧化机制也对这些方块生效。

为你带来更加真实、沉浸的机器搭建体验！

### 新增物品

- **铜锈时钟**: (**仅限创造模式**) `右键点击` 可将未涂蜡的方块推进到下一个氧化阶段，`长按右键` 可通过界面面板将方块调整到任意氧化阶段。

### 新增配方

- **推进氧化阶段**：通过`注液` 或 `批量洗涤`
- **涂蜡**：通过`注蜜` 或 `批量涂蜡（鼓风机+蜂蜜流体）`
- **脱蜡/除锈**：通过`使用握持斧或砂纸的机械手`或像打磨粗玫瑰石英一样，`手持砂纸`对其`右键`即可逐级除锈或脱蜡

## 配置

- **在 JEI 中折叠同类方块**: 若启用，**不**分别显示氧化变种，悬浮鼠标于未氧化物品上可浏览其变体。
- **启用移动式流体接口交叉匹配**: 若启用，不同氧化程度的移动式流体接口可以相互对接。
- **氧化整个流体储罐**: 若启用，自然氧化会让整个流体储罐多方块结构一起进入下一氧化阶段，大型储罐不再被拆分成支离破碎的独立小储罐。
- **工具作用于整个流体储罐**: 若启用，对流体储罐方块使用蜜脾涂蜡，或用斧/砂纸除蜡、除锈（手持或机械手）时，会作用于整个多方块储罐，大型储罐不会被拆散。
