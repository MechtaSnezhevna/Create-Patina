<h1 align="center">机械动力: 铜染光阴</h1>

一个机械动力附属模组，为含有铜材质的物品与方块添加了氧化变种及其氧化机制。

**其他语言版本:**
[English](../../README.md) | [简体中文](README.zh-CN.md)

## 特性

### 新增方块

为机械动力中**所有**含有铜材质的方块，添加了锈蚀的/斑驳的/氧化的/涂蜡的……共计 **7** 种氧化变种。

同时，原版的氧化机制也对这些方块生效。

为你带来更加真实、沉浸的机器搭建体验！

### 新增物品

- **铜锈时钟**: (**仅限创造模式**) `右键点击` 可将未涂蜡的方块推进到下一个氧化阶段，`长按右键` 可通过界面面板将方块调整到任意氧化阶段。

### 新增配方

- **推进氧化阶段**：通过`注液` 或 `批量洗涤`.
- **涂蜡**：通过`注蜜` 或 `批量涂蜡（鼓风机+蜂蜜流体）`.
- **脱蜡/除锈**：通过`使用握持斧或砂纸的机械手`.
